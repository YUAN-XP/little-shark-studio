个人制作 / CREATED BY ME

海洋模型、材质与动态效果

袁潇鹏制作

海洋由我在 Blender 中学习并制作，结合 Node Wrangler 完成材质节点。蓝色海水、浅蓝色泡沫、橙色夕阳和黄色海面反光，均来自我的海洋作品。网站保留了原文件第 1—400 帧的动态变化。

引用素材 / ADAPTED ASSET

海岛沙滩与背景道具

Stylized Tropical Beach Diorama，作者 Visthétique。

依据 Creative Commons Attribution 4.0 International（CC BY 4.0） 使用。

网站中的改编包括：将沙地调整为中央抬高的岛体，移除源场景中的水面、岩石及重复交互道具，重新摆放并优化躺椅、阳伞与植物，缩小贴图并调整材质。

上述素材仅用于沙滩与背景道具，不包括由袁潇鹏制作的海洋。原作者未为本网站背书。素材按原许可提供，不附带担保。

界面组件 / INTERFACE COMPONENTS

React Bits

导航玻璃效果基于 GlassSurface 调整；项目卡片边缘效果使用 BorderGlow。组件来自 David Haz 制作的 React Bits，已按网站布局适配。
